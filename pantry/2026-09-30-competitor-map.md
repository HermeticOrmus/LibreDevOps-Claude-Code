# Competitor map: LibreDevOps-Claude-Code

Run of 2026-09-30. Star counts come from the GitHub API (`gh api repos/<owner>/<repo>`) in this run; feature claims come from each project's README or catalog as fetched in this run. A blank or `?` cell means the source did not say.

## Product

- Name: LibreDevOps-Claude-Code, release v1.0.1, marketplace `libre-devops`
- Flagship: `kubernetes-operations` (agent `k8s-engineer`, command `/k8s`, skills `k8s-patterns` and `kubernetes-operations`)
- Our surfaces: 26 plugins in `.claude-plugin/marketplace.json`: 25 domain plugins (25 agents, 24 commands, 26 skills; `log-management` ships no command) plus `libre-devops-hooks` (SessionStart context, a PreToolUse `ask` before edits to Terraform state, credential, `.env`, key and secrets files, and PostToolUse infrastructure checks on Edit, Write and MultiEdit). Install with `/plugin marketplace add HermeticOrmus/LibreDevOps-Claude-Code` or `./setup.sh`. CI (`.github/workflows/validate.yml`) validates the marketplace and every plugin, then installs all of them into a clean config.
